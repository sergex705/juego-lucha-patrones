# Juego de Lucha - Refinamiento con Patrones

[![Java CI with Maven](https://github.com/sergex705/juego-lucha-patrones/actions/workflows/ci.yml/badge.svg)](https://github.com/sergex705/juego-lucha-patrones/actions/workflows/ci.yml)

## Descripción
Proyecto de refinamiento arquitectónico de un juego de lucha por turnos utilizando Patrones de Diseño.

## Patrones aplicados
- **Strategy:** Para la gestión dinámica de ataques.
- **Factory Method:** Para la creación eficiente de personajes.

## Comandos para ejecutar
- Para compilar: `mvn compile`
- Para probar: `mvn test`
